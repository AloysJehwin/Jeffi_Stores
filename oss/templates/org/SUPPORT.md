# Support

These repositories are for the Jeffi Stores code. If you run a store on Jeffi Stores and need help with your account, email support@jeffistores.in. If you bought something from a store, contact that store.

## Bugs and feature requests

Open an issue in the repository the bug or idea belongs to; the [org page](https://github.com/Jeffi-ERP) says what each one holds. If you are not sure which, use [workspace](https://github.com/Jeffi-ERP/workspace/issues). Fill in the issue form, and never paste secrets, customer data or order details.

## Questions

Ask in [Discussions on workspace](https://github.com/Jeffi-ERP/workspace/discussions): setting up the workspace, how something works, or whether a change would be accepted. Search first; it may already be answered.

Maintainers answer issues and discussions when they can. There is no guaranteed response time.

## Security

Report vulnerabilities privately as described in [SECURITY.md](https://github.com/Jeffi-ERP/.github/blob/main/SECURITY.md), never in an issue or discussion.

## Commercial licensing

Production use of the code needs a commercial licence from Jeffi Stores until the Change Date, 2030-09-30. Email support@jeffistores.in.

## Anything private

Email support@jeffistores.in for anything that shouldn't be public, including Code of Conduct reports.
