# Jeffi ERP community files

Default community health files for every repository in [Jeffi ERP](https://github.com/Jeffi-ERP): the contributing guide, code of conduct, security, support and governance policies, and the issue and pull request templates. A repository with its own copy of one of these files uses that instead. `profile/README.md` is the org landing page and `assets/` holds the logo.

These files are generated from the upstream repository, [AloysJehwin/Jeffi_Stores](https://github.com/AloysJehwin/Jeffi_Stores), so propose changes in an issue rather than a pull request.
