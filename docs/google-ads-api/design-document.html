Jeffi Stores: Google Ads API Tool

Design document for the Google Ads API developer token application
Company: Jeffi Stores, https://jeffistores.in · API contact: admin@jeffistores.in
Google Ads manager account (MCC): 587-534-7299 · Google Cloud project number: 658812117189

1. Company and product

Jeffi Stores is an e-commerce platform for small and medium retailers in India. Each retailer ("store") gets an online shop and a private admin panel for catalogue, orders, payments, shipping, finance and marketing. Jeffi Stores also runs its own flagship store on the same platform.

The Google Ads tool is the "Google Ads" section of the store admin panel. It lets a store owner manage and measure their own Google Ads account without leaving the platform, and connect their ad spend to the orders the store actually receives.

2. Users and access

  • External users: store owners and their staff on the platform. Each store connects its own Google Ads account and only ever sees and changes that account.
  • Internal users: the Jeffi Stores team, for the flagship store's own account and for support.
  • Inside a store, access is role-based: viewing reports needs a read permission; any change needs a separate write permission. Every change is logged with the admin who made it.

3. How an account is connected (authentication)

  • Google sign-in (OAuth 2.0, web server flow). The store owner clicks "Connect with Google", signs in with a Google account that has access to their Ads account, and grants the https://www.googleapis.com/auth/adwords scope (and datamanager for conversion uploads). The request uses access_type=offline and a signed, time-limited state parameter. The refresh token is encrypted (AES-256-GCM) and stored per store; it is never shown in the UI or logs.
  • Account picker. After sign-in the tool lists the accounts the user can reach (CustomerService.ListAccessibleCustomers and customer_client under any manager account) and the owner chooses one.
  • Optional "managed by Jeffi Stores". A store may instead have its account linked under the Jeffi Stores manager account (587-534-7299) through a standard manager link invitation (CustomerClientLinkService) that the store owner accepts in Google Ads. The tool then uses the manager's credentials with login-customer-id. The store can unlink at any time.
  • Disconnecting deletes the stored token. The developer token is held only on our servers and is never exposed to stores or browsers.

5. Data flow and schedule

  • Reporting sync: full structure and 30-day metrics every 24 hours; a lighter refresh of recent metrics every 3 hours; on-demand "Sync now". Results are stored per store and the screens read from our database, so viewing a report does not call the API.
  • Conversion uploads: every 30 minutes, only newly paid orders, each sent once (order id as the deduplication key).
  • Audiences: refreshed once every 24 hours with only additions and removals.
  • Digest: weekly, from stored data.
  • Jobs run per store with a lock so the same account is never synced twice at once.

6. API usage and rate limits

  • API version: Google Ads API v26 (REST). Reports use SearchStream to minimise request counts.
  • Expected volume per store: about 10 to 30 read requests per sync, a handful of mutate requests per day when the owner makes changes, and up to 48 small conversion uploads per day. At our current scale this is well under 2,000 operations per day across all stores.
  • Requests retry with exponential backoff and honour RESOURCE_EXHAUSTED / quota errors; a failed job is retried on the next schedule rather than in a tight loop.

7. Data handling and privacy

  • Each store's Google Ads data is stored in that store's own database and is never shown to another store.
  • OAuth refresh tokens are encrypted at rest; the developer token and client secret are server-side secrets.
  • Conversion and Customer Match data are normalised and SHA-256 hashed before upload. Email and phone are sent only when the buyer accepted ad cookies at checkout; otherwise only the click identifier is used.
  • We do not sell, share or resell Google Ads data, and we do not use one store's data for another store.
  • Disconnecting the account stops all API calls for that store and removes its stored credentials.

8. Compliance

  • Changes are made only on explicit user action (or on schedules the owner turned on) and are logged with the acting user.
  • Store owners agree to Google's Customer Match terms in their own Google Ads account before audiences are uploaded; the tool checks the acceptance status first.
  • The tool is built and operated by Jeffi Stores; no third-party tool uses our developer token.
